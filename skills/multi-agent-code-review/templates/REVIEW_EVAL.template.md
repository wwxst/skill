## 评测原则

- 真实 Bug 发现能力优先。
- 误报必须单独统计，不能只统计发现数量。
- 任何 Prompt、Skill、工具或模型变更，都应重新运行同一评测集。
- 不得因为 Review 轮数减少，就认定质量提升。
- Revert 和事故率是最终质量护栏。
