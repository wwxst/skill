# Multi-Agent Code Review 报告

## 1. 最终结论

- **状态：** PASS / PASS WITH WARNINGS / FAIL / NEEDS HUMAN
- **审查范围：** 分支、提交、PR 或 diff 范围
- **风险等级：** Low / Medium / High / Critical
- **实际创建 Agent：** N 个；完成 N 个；失败/超时 N 个
- **已确认问题：** N 个
- **已修复问题：** N 个
- **误报/排除：** N 个
- **测试：** N 项通过 / N 项失败 / N 项未运行
- **开发者是否需要处理：** 是 / 否

> 如果没有真实创建独立子 Agent，必须在这里醒目标注：**未执行多 Agent 审查**，说明缺失能力和开发者是否同意降级。

## 2. 主 Agent 做了什么

按实际执行顺序概述，不写计划冒充执行结果。

1. **确认范围：** 检查了哪个分支、基准提交、工作区和 diff。
2. **读取资料：** 读取了哪些 Skill 规则、项目说明和局部规范。
3. **环境能力：** 是否确认支持独立上下文、并行启动和结果回收。
4. **基础验证：** 实际运行了哪些测试、构建、Lint 或类型检查。
5. **Agent 调度：** 创建了哪些 Agent，分别负责什么。
6. **结果处理：** 如何汇总、投票、确认问题和决定修复。
7. **复审结束：** 进行了几轮，为什么结束。
