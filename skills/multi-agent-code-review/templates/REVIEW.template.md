## 3. 这个项目里的“故障”是什么

请描述可以观察到的真实失败表现，而不是泛泛要求“代码优雅”。

| 区域 | 真实失败表现 | 审查时必须验证什么 |
|---|---|---|
| 文档 | 文档描述与实际行为不一致 | 对照代码、配置和实际输出 |
| 配置 | 请求被路由到错误目标 | 检查解析、默认值和调用链 |
| 权限 | 用户访问了不属于自己的资源 | 检查身份、授权和资源归属 |
| 任务执行 | 任务失败后无法恢复或状态不一致 | 检查状态转换、重试和取消 |
| 工具执行 | 返回结果与实际副作用不一致 | 检查执行结果、异常和副作用 |

请按项目实际情况修改或删除示例。

## 12. Reviewer 自检

每次审查结束时，确认 Reviewer 是否：
- 读取并遵守本文件；
- 对每个问题提供文件和行号；
- 只报告真实故障；
- 正确跳过指定路径；
- 在报告开头给出问题数量；
- 没有问题时明确写 0。
