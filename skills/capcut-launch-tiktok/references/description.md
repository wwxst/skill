# 视频简介（TikTok 描述）

## 一、简介不是文案，是搜索入口

| | 视频字幕 | 视频简介 |
|---|---|---|
| 对象 | 正在看的人 | TikTok 搜索框 |
| 作用 | 让人看懂该点哪 | 让搜的人找到这条 |
| 长度 | 每句 4–7 词 | 20–30 行 |

两者分工不同，不要互相抄。

## 二、四层结构

### 第 1 层：三行正文

| 行 | 作用 | 写法 |
|---|---|---|
| 1 | 标题 | **和视频第一句字幕一模一样**，末尾加 emoji |
| 2 | 情绪钩子 | 第一人称、制造"我也想要"、可以略带荒诞感 |
| 3 | 卖点 + 品牌词 | 必须出现 `CapCut` 和 `template` |

真实样板（80 年代风）：

```
How to do the 80s trend ✨
I don't know if I woke up in September 2026 or September 1980.
Turn your photo into vintage 80s look with this CapCut template.
```

第 2 行那种"我分不清是 2026 还是 1980"的写法，比"这个滤镜好酷"有效得多——它给的是一个**画面**，不是一句评价。

### 第 2 层：5 行短关键词（不带 #）

```
80s trend capcut
80s retro photo effect
how to do the 80s trend
80s style filter
ai 1980s photo tutorial
```

规则：
- 每行 3–5 个词
- 一行一个搜索意图
- 其中一行必须**重复第 1 行的标题**（加权）
- 不带 `#`，这是搜索短语不是话题

### 第 3 层：6–10 行长尾词

抓"真实用户会怎么敲搜索框"：

| 类型 | 例子 |
|---|---|
| 疑问句 | `como se hace el trend de los 80` |
| 带工具名 | `como hacer foto de los 80 en chat gpt` |
| 带场景 | `como hacer foto de los 80 en pareja` |
| 带平台 | `como hacer la foto de los 80 en instagram` |
| 带 prompt 词 | `foto de los 80 chat gpt prompt` |
| **故意拼错** | `como se hace el trend de los 80 en caht gpt` |

**错别字是故意的。** 真人搜索会打错，把错拼版本也列进去，等于多一个入口。

### 第 4 层：5 个话题

```
#trenddelos80 #80sTrend #TendenciaAños80 #capcut #capcutpioneer
```

- 2 个趋势词（带地区变体）
- 2 个品牌词（`#capcut` `#capcuttemplate`）
- 1 个计划词（`#capcutpioneer` 是 CapCut 官方合作计划）

## 三、多语言策略

样板是 **英/西/葡三块并列**，最后一大坨长尾是西语——说明主力市场是西语区。

| 账号阶段 | 建议 |
|---|---|
| 起步 / 单市场 | **只写一种语言**，把长尾写厚 |
| 已跑量 / 多市场 | 每块 3 行正文 + 5 行短词，长尾只放主力语言 |

三语并列会稀释算法对"这条视频属于哪个语言区"的判断，起步阶段不划算。

## 四、安全上限

| 项 | 上限 |
|---|---|
| 总行数 | **30 行以内** |
| 正文 | 3 行 |
| 短关键词 | 5 行 |
| 长尾 | 6–10 行 |
| 话题 | 5 个 |

超过 30 行容易被判"关键词堆砌"，风险上升。

## 五、交付模板

```
{第一句字幕原文} ✨
{第一人称情绪钩子，一行}
{Turn your photo into ... with this CapCut template.}

{短关键词 ×5，每行一个}

{长尾 ×6–10，每行一个}

{话题 ×5}
```

## 七、复查清单

- [ ] 第 1 行和视频第一句字幕**逐字一致**
- [ ] 第 3 行含 `CapCut` 和 `template`
- [ ] 短关键词里有一行重复标题
- [ ] 长尾里至少 1 条错拼、1 条疑问句、1 条带场景
- [ ] 总行数 ≤ 30
- [ ] 话题 5 个，含 2 个品牌词
- [ ] 只写目标市场的语言（除非已跑量）
