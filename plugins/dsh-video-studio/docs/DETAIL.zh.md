# Video Studio

Video Studio 为 DeepSeek Harness 增加本地视频制作工具。AI 可以创建项目、导入素材、读取媒体信息、编排时间线、写入 SRT 字幕、添加背景音乐或旁白音轨，并提交 FFmpeg 渲染任务。

## 能做什么

- 视频、图片、音频素材导入与管理
- 9:16、16:9、1:1 画幅和自定义分辨率
- 多片段顺序剪辑、源入点/出点、变速、裁切或留边
- 背景音乐与旁白混音
- SRT 字幕文件保存，可选择烧录到画面
- 后台渲染任务、进度查询和取消
- MP4 成片预览与工程数据保存

## 目前边界

当前版本不包含自动语音识别、AI 语音合成、自动选镜头、复杂转场、专业节点调色、模板市场或剪映草稿原生导出。字幕需要提供 SRT 文本；配音和音乐需要先作为音频素材导入。项目会保留时间线 JSON，后续可在此基础上增加更多制作能力。

需要 Node.js 24.9+、FFmpeg 7+ 和 FFprobe 7+。所有处理在本机完成，原始素材不会被改写。
