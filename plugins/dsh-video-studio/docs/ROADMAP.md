# Roadmap

## 0.1.0 — 可运行核心

- Harness Host Bundle 与中文工具注册
- 项目、素材、时间线、revision 保护
- FFmpeg 视频/图片片段处理与 MP4 输出
- 原视频声音、背景音乐、旁白混合
- SRT 字幕保存与烧录
- 后台渲染任务和本地工作台

## 0.2.0 — 模板与动态画面

- 图片片段推近、拉远和上下左右平移动画
- 淡入、溶解、擦除、滑动、圆形和像素化转场
- ASS 动态文字叠加，支持淡入/淡出、位置、字号和颜色
- 内置电影感图片转场模板
- 将当前图片时间线保存为 JSON 模板，并在其他项目复用
- 对动画、转场和文字叠加参数做统一校验
- 增加真实 FFmpeg 模板渲染与复用集成测试

## 0.3 — 素材自动获取

- 素材搜索提供方接口
- Pixabay API 搜索和按需下载
- 本地素材库、标签和去重
- 素材来源与授权信息记录

## 0.4 — AI 内容与素材生产

- 根据选题和脚本自动生成镜头清单
- AI 图片生成提供方接口
- 按镜头需求自动搜索、生成和筛选素材
- 模板参数自动填充与多版本生产

## 0.5 — 质量检查与批量生产

- 黑场、静帧、画面异常和音频响度检查
- 字幕安全区和可读性检查
- 批量渲染、失败重试和任务恢复
- 与 TikTok 内容知识库、选题 Skill 和真实发布数据反馈连接

## 暂不纳入

- 训练专用视频模型
- 重写 DeepSeek Harness 内核
- CapCut 原生模板工程与剪映草稿格式
- 专业级多轨合成、节点调色和复杂特效系统

所有后续能力都以真实实现和可复现测试为准，不因工具接口存在就宣称能力完成。
