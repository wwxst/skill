# Roadmap

## 0.1.0 — 可运行核心

- Harness Host Bundle 与中文工具注册
- 项目、素材、时间线、revision 保护
- FFmpeg 视频/图片片段处理与 MP4 输出
- 原视频声音、背景音乐、旁白混合
- SRT 字幕保存与烧录
- 后台渲染任务和本地工作台

## 后续迭代建议

### 0.2 — 内容理解与字幕

- 抽取关键帧和联系表，方便人工或视觉模型检查素材
- 接入本地 ASR，生成带时间戳的字幕草稿
- 口播停顿检测和初剪建议
- 字幕样式预设和多语言字幕

### 0.3 — 模板与批量生产

- 原创 TikTok 视频模板和镜头结构模板
- 模板参数化、批量变体和不同画幅导出
- 素材标签、搜索和选片单
- 音乐节拍分析和卡点辅助

### 0.4 — 声音与视觉增强

- 可配置 TTS 提供方和本地语音引擎
- 更多转场、文字动画和基础调色
- 音量响度检测、黑场/静帧/字幕安全区检查

### 0.5 — 人工续剪与运营联动

- 剪映草稿或交换格式导出（需逐格式验证）
- 批量输出与失败重试
- 与 TikTok 内容知识库、选题 Skill 和真实发布数据反馈连接

所有后续功能都以真实实现和可复现测试为准，不因工具接口存在就宣称能力完成。
