# Roadmap

> 状态以代码、测试和真实外部服务能力为准；接口已实现不等于用户已完成第三方账号授权。

## 0.1.0 — 可运行核心：已完成

- Harness Host Bundle 与中文工具注册
- 项目、素材、时间线、revision 保护
- FFmpeg 视频/图片处理与 MP4 输出
- 音频混合、SRT 字幕和本地工作台

## 0.2.0 — 模板与动态画面：已完成

- 图片推近、拉远和平移动画，多种转场
- ASS 动态文字
- 内置模板、JSON 模板保存和跨项目复用
- 参数校验和真实渲染集成测试

## 0.3.0 — 素材自动获取：代码完成，待 API Key 实测

- Pixabay 图片/视频搜索、分页和 24 小时缓存
- 按需下载、域名/重定向/大小/文件类型限制
- 本地素材库、SHA-256 去重、标签和跨项目导入
- 素材来源、作者、来源页和授权元数据

## 0.4.0 — AI 内容与素材生产：代码完成，待 API Key 实测

- Harness 当前模型按选题和脚本规划结构化镜头清单
- OpenAI Images API 兼容图片生成
- 镜头素材搜索、生成、绑定
- 镜头清单编译时间线并自动填充模板
- 多画幅、多标题版本复制

## 0.5.0 — 质量检查与批量生产：核心代码完成，待授权实测

- 黑场、静帧、静音和音频响度检查
- SRT 字幕速度/行长和动态文字可读性启发式检查
- 批量渲染、单项失败隔离、失败任务重试和中断任务恢复
- TikTok 多账号 OAuth 授权、每账号独立 state/令牌和 refresh token 轮换
- Display API 作品列表及播放/点赞/评论/分享同步
- 真实发布数据补录主页访问、关注和 CPS 转化
- 按具体 accountId、账号类型、选题、开头和模板汇总真实表现

## 外部依赖与能力边界

- Pixabay 搜索/下载需要用户自己的 API Key。
- 图片生成需要用户自己的兼容 Images API Key；生成前必须明确确认可能产生费用。
- TikTok 自动同步需要开发者应用获批 Login Kit / Display API 的 `video.list` scope，并由用户授权账号；每个账号需使用唯一 accountId 单独授权。
- TikTok Display API 不提供主页访问、关注、下载/注册或 CPS 转化数据，这些指标需要从业务后台导入或手动录入。
- 当前不声称已连接 CapCut CPS 后台；没有官方权限的私有数据不抓取。
- 自动质量检查不能替代人工审片。

## 暂不纳入

- 训练专用视频模型、重写 DeepSeek Harness 内核
- CapCut 原生模板工程与剪映草稿格式
- 专业级多轨合成、节点调色和复杂特效系统
- 未经授权的 TikTok 私有数据抓取或登录态模拟
