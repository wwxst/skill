# 美区 TikTok · CapCut 图片模板生产规范（无需 AI 视频）

> 目标：DeepSeek Harness 使用真实图片、可授权素材或单独生成的 AI 静态图片，完成可展示的 9:16 模板式 TikTok MP4。禁止误认为 MP4 = CapCut 原生模板。

## 一、先决定目标

| | 拉新（acquisition） | 拉活（activation） |
|---|---|---|
| 核心目标 | 让未使用过 CapCut 的目标用户产生尝试需求，并通过实际活动规则定义的有效行为转化 | 以视觉效果和播放分发吸引已装用户使用对应模板 |
| 叙事重点 | 先展示成片效果，再展示原图/步骤，CTA 必须与真实锚点对齐 | 展示好看的前后反差、卡点和照片转场，少硬口播 |
| 参考片长 | 7–13 秒（依实际脚本调整） | 6–12 秒（依视觉节奏调整） |
| 字幕 | 英文、动词和操作提示，原则上尽早出现锚点指引 | 简短英文标题或零字幕 |
| 优先指标 | 实际锚点点击、真实有效转化；无数据不作结论 | 播放、前 3 秒留存、完播、真实模板使用 |
| 必备前提 | 对应 CapCut 原生模板与 TikTok 系统锚点必须真实存在并可用 | 对应模板可用性同样需要核实 |

## 二、三种现成视频展示预设

1. `us-photo-reveal-acquisition`：4 个素材槽位。成片结果 → 原图 → 视觉变换 → 成片结果。首屏是英文结果型钩子，静止镜头防止抖动。未核验模板锚点之前不要把 demo 当作已可发布的拉新成片。
2. `us-photo-transition-activation`：7 个素材槽位。多张照片的快切、一次短擦除、结果定格；背景音乐需有合法许可并按实际节奏微调时间点。
3. `us-photo-memory-recap`：6 个素材槽位。适合 college year、graduation、pet growth、family memories、travel recap 等美国用户容易代入的个人回顾内容。

模板内容必须是**真实可复用的照片编辑结果**，不能用无关夜景照片拼成“情绪片”冒充模板。照片重复可使用同一项目素材 ID；严格禁止把真实人物肖像或品牌 Logo 作为未经许可的素材。

## 三、素材与风格

- 搜索默认使用英文关键词（`lang=en`），先确定具体受众/场景。例如 `graduation portrait before after`、`college friends camera roll`、`pet puppy to adult photos`、`outfit mirror selfie transition`。
- US market = 美国观众能理解的故事与场景，不等于必须拍纽约街景。优先自有照片和有授权的生活画面，不能靠文字硬贴美国地域标签。
- AI 静态图可以用于创意预览，但若内容要让用户替换自己的照片，必须证明目标 CapCut 模板有真实可替换槽位。单张 AI 视频效果不能替代真实原生模板功能。
- 背景音乐用 TikTok 商用音乐库或明确允许该用途的素材；不要把普通热门版权歌曲直接内置到可复用 MP4。
- 输出：竖屏 1080×1920，30fps；关键人物与英文文字位于安全区域；避免文本压在 TikTok 底部系统按钮上。

## 四、工作流与质量门槛

`video_template_list` 选择 goal → 搜索/导入图片 → `video_project_create` → `video_asset_import` / `video_library_import` → `video_template_apply` → 核对时间线 → 合法配乐 → `video_render` → `video_quality_check` → 人工预览 → 发布时验证真实 CapCut 模板与锚点。

质量检查不仅是分辨率、FPS 和黑场。人工还要确认相邻帧不抖动、无错位、开头能看到结果、所有字幕为自然英文、素材符合预期故事，且拉新/拉活不会混用 CTA。模板视频不能自行声称已挂系统级锚点。

## 五、用户已反馈失败样本

`模板样片_夜色霓虹_9x16_v4.mp4` 使用多张东亚雨夜霓虹照片和中文诗意字幕，约 18 秒。其内容不是美国受众的可替换照片转场范例；同时受强制 zoom-in 与 zoompan 像素裁切影响可能出现微小画面跳动。此片只用于技术问题回归，不作为合格美区模板样本。

## 六、流行趋势与复盘

具体趋势会变化，候选模板需要每次发布前核对 CapCut 模板页、TikTok 原片及 US 受众反馈。没有真实数据时只能说内容潜力，不能宣称达到某个转化率或播放成绩。新用户价格、有效行为与拉活计价以实际项目规则为准。
